# จำลองการชำระ Subscription ผ่าน PaymentProvider

ต้องการแสดงวงจรรายได้ของผลิตภัณฑ์ แต่โปรเจกต์นี้ไม่ได้รับเงินจริง เราจึงใช้ `MockPaymentProvider` กับหน้าชำระเงินของ RepairFlow เองที่ระบุชัดว่าเป็นโหมดสาธิต ไม่มีช่องกรอกบัตรและไม่มีโลโก้ Stripe เพราะหน้าเลียนแบบผู้ให้บริการชำระเงินอาจถูกมองเป็น phishing

Mock ส่ง event ที่ลงลายเซ็น HMAC เข้า webhook endpoint จริงของระบบ ทำให้วงจร Trial, active และ expired รวมถึงการรับ event ซ้ำยังถูกทดสอบจริง

## Consequences

- ถ้าจะทำเป็นของจริงต้องเพิ่ม `StripePaymentProvider` และย้ายออกจาก Vercel Hobby ซึ่งจำกัดเฉพาะการใช้งานที่ไม่ใช่เชิงพาณิชย์
- Portfolio ต้องระบุว่าการชำระเงินเป็นการจำลอง
