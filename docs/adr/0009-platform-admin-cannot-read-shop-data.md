# Platform Admin อ่านข้อมูลของร้านไม่ได้

ระบบหลายร้านมักให้ผู้ดูแลเข้าถึงข้อมูลทุกร้านเพื่อช่วยเหลือ แต่ RepairFlow จำกัด Platform Admin ให้ดูรายชื่อร้าน สถานะ Subscription ตัวเลขการใช้งานรวม และระงับร้านได้เท่านั้น โดยไม่อ่าน Work Order หรือข้อมูล Customer และไม่มี impersonation เพราะการ bypass RLS ทั้งระบบจะทำลายขอบเขตตาม ADR-0001

Platform Admin ใช้ DB role แยกที่เข้าถึงเฉพาะตาราง platform และ view ตัวเลขรวม บัญชีสร้างผ่าน CLI เท่านั้น และทุกการกระทำถูกบันทึก Audit Log ข้อแลกเปลี่ยนคือการช่วยเหลือร้านจะทำผ่านหน้าจอไม่ได้ ถ้าต้องเข้าถึงข้อมูลจริงต้องเป็นงานนอกระบบที่ตั้งใจทำและมีบันทึก
