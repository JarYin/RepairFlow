# แจ้งเตือนในแอปเท่านั้น ไม่ส่งอีเมล

โปรเจกต์นี้เป็นงานแสดงผลงานที่ต้องฟรี การส่งอีเมลโดยไม่มีโดเมนของตัวเองส่งถึงกล่องจดหมายได้ไม่แน่นอน และต้องเพิ่ม outbox กับ scheduler ซึ่ง Vercel Hobby รันได้วันละครั้ง เราจึงเขียน Notification ใน transaction เดียวกับเหตุการณ์ และไม่มีการส่งออกนอกแอป

เอกสารตั้งต้นระบุปัญหาว่าลูกค้าไม่ได้รับแจ้งเมื่องานเสร็จ แต่ Notification ไปไม่ถึงคนที่ไม่ล็อกอิน จึงมี Customer Contact Task ให้พนักงานติดต่อเองและบันทึกผล ซึ่งเป็นข้อจำกัดที่ต้องระบุใน Portfolio

## Consequences

- เชิญ, reset password และการสมัครร้านไม่มีการยืนยันทางอีเมล ดู ADR-0003
- กันการสมัครเกินควรด้วยการจำกัดต่อ IP, เพดานต่อวัน และการลบร้านที่ไม่ใช้งาน
- ดึง Notification ตอนเปิดหน้าหรือกลับมาที่แท็บ ไม่ทำ realtime หรือ polling เพื่อไม่ให้ DB ตื่นตลอดและกิน quota ของ Neon
