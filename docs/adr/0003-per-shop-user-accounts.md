# แยกบัญชีผู้ใช้ต่อร้าน ไม่ใช้บัญชีกลาง

ระบบไม่ส่งอีเมล (ADR-0006) จึงไม่มีวิธียืนยันว่าเจ้าของอีเมลหรือเบอร์โทรเป็นคนเดียวกันข้ามร้าน ถ้าใช้บัญชีกลาง พนักงานร้าน A ที่ออกลิงก์ reset ให้ลูกค้าจะเข้าถึงข้อมูลของลูกค้าคนนั้นที่ร้าน B ได้ เราจึงให้ `users` ไม่ซ้ำตาม `(shop_id, login_id)` อยู่ภายใต้ RLS และล็อกอินที่ `/s/:shopSlug/login` ซึ่งตัดความเสี่ยงนี้ออกตั้งแต่โครงสร้าง

## Considered Options

- **บัญชีกลางร่วมกับ memberships:** คนเดียวใช้ได้หลายร้าน แต่ต้องมีกฎเพิ่มว่าร้านออก reset ได้เฉพาะบัญชีที่อยู่ร้านเดียว และห้ามเชื่อมบัญชีอัตโนมัติ เดิมเลือกทางนี้ก่อนตัดอีเมลออก

## Consequences

- คนที่เกี่ยวข้องกับหลายร้านต้องมีหลายบัญชี
- `login_id` ของ Customer คือเบอร์โทรที่ไม่ได้ยืนยันด้วย OTP
- เชิญและ reset ใช้ลิงก์หรือ QR แบบใช้ครั้งเดียวที่พนักงานส่งให้เอง ส่วน Owner ใช้ recovery codes และถ้าหายต้องกู้ผ่าน CLI ของ Platform Admin พร้อมบันทึก Audit Log
- Platform Admin อยู่ในตารางบัญชีแยกต่างหาก เพราะไม่ได้เป็น User ของร้านใด
